# 晨翼Agent 架构设计

## 边缘计算 + 云端同步架构

### 核心理念

- **内核在本地**：每个设备运行自己的Rust内核，负责AI推理、工具执行、设备控制
- **云端只同步**：用户认证、数据存储、设备状态、消息路由
- **设备间P2P**：任意设备间直接通信，云端只做路由

### 云端职责（轻量级）

**只做数据同步，不做计算**：

1. **用户认证**
   - 注册、登录
   - JWT Token生成和验证
   - 用户信息存储

2. **数据同步**
   - 会话历史存储和同步
   - 任务队列存储和同步
   - 向量记忆存储和同步
   - 用户配置同步

3. **设备管理**
   - 设备注册和在线状态
   - 设备能力声明（控制、投屏等）
   - 设备间消息路由

4. **WebSocket路由**
   - 设备连接管理
   - 消息转发（设备间P2P）
   - 心跳检测

### 本地内核职责（重量级）

**所有计算都在本地**：

1. **AI推理**
   - LLM对话（智谱、MiniMax等）
   - Function Calling
   - 流式响应

2. **工具执行**
   - 系统命令执行
   - 文件操作
   - 网络请求

3. **设备控制**
   - 手机投屏（H.264视频流）
   - 手机控制（点击、滑动、输入）
   - 电脑控制（鼠标、键盘）

4. **记忆检索**
   - 向量索引（HNSW）
   - 相似度搜索
   - 本地向量数据库

### 工作流程

#### 1. 用户登录

```
用户打开Electron → 输入账号密码 → 云端验证 → 返回JWT Token
→ 本地内核初始化 → 设备注册到云端 → 连接WebSocket
```

#### 2. 创建会话

```
用户在电脑端创建会话 → 本地内核创建会话 → 云端存储会话元数据
→ 同步到所有设备 → 手机端也能看到这个会话
```

#### 3. AI对话

```
用户在电脑端发送消息 → 本地Rust内核调用LLM → 流式返回结果
→ 云端存储对话历史 → 同步到所有设备
```

#### 4. 跨设备控制

```
电脑端创建任务：控制手机A打开微信
→ 云端路由消息到手机A → 手机A的本地内核执行
→ 结果返回电脑端 → 云端存储任务结果
```

### 数据同步策略

**实时同步**：
- 会话创建/更新 → 立即同步
- 任务创建/完成 → 立即同步
- 记忆保存 → 立即同步

**增量同步**：
- 设备上线 → 拉取最新会话列表
- 设备离线 → 下次上线时同步

**冲突解决**：
- 会话：最后修改时间优先
- 任务：状态机保证一致性
- 记忆：向量去重

### 技术栈

**云端**：
- Node.js + Fastify（HTTP API）
- WebSocket（实时通信）
- PostgreSQL（关系数据）
- Redis（缓存 + 消息队列）

**本地内核**：
- Rust（高性能）
- SQLite（本地存储）
- HNSW（向量索引）
- NAPI-RS（Node绑定）

**Electron客户端**：
- Electron 28
- React/Vue（UI）
- Rust内核（NAPI绑定）

**Android客户端**：
- Kotlin
- Rust内核（JNI绑定）
- Jetpack Compose（UI）

### 优势

1. **低延迟**：本地内核计算，毫秒级响应
2. **高可用**：断网也能本地运行，联网后自动同步
3. **隐私保护**：敏感数据在本地处理，云端只存元数据
4. **跨设备协作**：任意设备间P2P通信
5. **弹性扩展**：云端只做同步，压力小，易扩展
