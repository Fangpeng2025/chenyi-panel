# 晨翼Agent v1.0 技术架构文档

## 一、整体架构

### 1.1 架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                        云端服务                              │
│  ┌───────────┐  ┌───────────┐  ┌───────────┐  ┌─────────┐ │
│  │ 账号系统  │  │ 设备管理  │  │ 任务调度  │  │ 消息路由│ │
│  └───────────┘  └───────────┘  └───────────┘  └─────────┘ │
│  ┌─────────────────────────────────────────────────────────┐│
│  │              WebSocket 网关 + HTTP API                  ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
         ▲              ▲              ▲              ▲
         │              │              │              │
    ┌────┴────┐    ┌────┴────┐    ┌────┴────┐    ┌────┴────┐
    │ 手机A   │    │ 手机B   │    │ 电脑A   │    │ 电脑B   │
    │ Agent   │    │ Agent   │    │ Agent   │    │ Agent   │
    └─────────┘    └─────────┘    └─────────┘    └─────────┘
```

### 1.2 核心理念

- **设备 = 执行终端**：手机、电脑只是操作工具
- **云端 = 大脑**：所有智能逻辑、状态管理在云端
- **账号为中心**：登录后即可使用任意设备
- **跨设备控制**：任意设备可控制任意其他设备

### 1.3 功能矩阵

| 功能 | 手机端 | 电脑端 | 云端 |
|------|--------|--------|------|
| 设备控制 | ✓ 执行 | ✓ 执行 | 路由 |
| 投屏 | ✓ 推流 | ✓ 接收 | 信令 |
| 文件同步 | ✓ | ✓ | 存储 |
| 任务执行 | ✓ | ✓ | 调度 |
| AI对话 | ✓ | ✓ | 核心 |
## 二、通讯协议设计

### 2.1 协议分层

```
┌────────────────────────────────────────────────────┐
│                    协议分层                         │
├────────────────────────────────────────────────────┤
│  控制层    │  WebSocket (JSON)                     │
│  (指令/状态)│  - 设备注册、心跳                     │
│            │  - 跨设备控制指令                      │
│            │  - 任务下发、状态上报                  │
├────────────┼───────────────────────────────────────┤
│  数据层    │  HTTP/2 (REST)                        │
│  (文件/配置)│  - 文件上传下载                        │
│            │  - 配置同步                            │
├────────────┼───────────────────────────────────────┤
│  流媒体层  │  WebRTC (P2P)                         │
│  (投屏/语音)│  - 实时视频流                          │
│            │  - 点对点传输                          │
└────────────┴───────────────────────────────────────┘
```

### 2.2 WebSocket 控制层

**连接地址**: `wss://cloud.chenyi.com/ws?token={jwt_token}`

**心跳机制**:
- 客户端每30秒发送 `{"type": "ping"}`
- 服务端响应 `{"type": "pong"}`
- 超时60秒未响应则断开

### 2.3 HTTP 数据层

**基础地址**: `https://cloud.chenyi.com/api/v1`

**主要接口**:
- `POST /auth/login` - 用户登录
- `GET /devices` - 获取设备列表
- `POST /files/upload` - 文件上传

### 2.4 WebRTC 流媒体层

**使用场景**: 投屏、语音通话

**流程**: 云端只做信令交换，视频流P2P直传

## 三、消息格式定义

### 3.1 通用消息结构

```json
{
  "type": "消息类型",
  "requestId": "请求ID（可选）",
  "timestamp": 1234567890,
  "data": {}
}
```

### 3.2 设备注册

```json
// 请求
{
  "type": "register",
  "data": {
    "deviceId": "device_abc123",
    "deviceType": "android|electron",
    "deviceName": "realme RMX3888",
    "capabilities": ["screen_stream", "control", "file_sync"]
  }
}

// 响应
{
  "type": "register_ack",
  "data": {
    "success": true,
    "deviceId": "device_abc123"
  }
}
```

### 3.3 控制指令

```json
// 点击指令
{
  "type": "control",
  "requestId": "req_001",
  "target": "device_abc123",
  "data": {
    "action": "tap",
    "params": {"x": 500, "y": 300}
  }
}

// 执行结果
{
  "type": "control_result",
  "requestId": "req_001",
  "data": {
    "success": true,
    "message": "点击成功"
  }
}
```

### 3.4 任务下发

```json
{
  "type": "task",
  "taskId": "task_001",
  "target": "device_abc123",
  "data": {
    "command": "screenshot",
    "params": {}
  }
}
```

### 3.5 状态同步

```json
{
  "type": "sync",
  "data": {
    "deviceId": "device_abc123",
    "status": "idle|busy|offline",
    "battery": 85,
    "network": "wifi"
  }
}
```

## 四、设备控制流程

### 4.1 设备注册流程

```
客户端                    云端
  │                        │
  ├──── register ─────────>│
  │                        ├─ 保存设备信息
  │<─── register_ack ──────┤
  │                        │
  ├──── ping (30s) ───────>│
  │<─── pong ──────────────┤
  │         ...            │
```

### 4.2 跨设备控制流程

```
手机A                     云端                      电脑B
  │                        │                        │
  ├─ control(target=B) ───>│                        │
  │                        ├─ 转发到B ─────────────>│
  │                        │                        ├─ 执行操作
  │                        │<── result ─────────────┤
  │<── result ─────────────┤                        │
```

### 4.3 投屏流程

```
手机A                     云端                      电脑B
  │                        │                        │
  │<── 请求投屏 ───────────┼────────────────────────┤
  ├─ SDP Offer ───────────>│                        │
  │                        ├─ 转发Offer ───────────>│
  │                        │<── SDP Answer ─────────┤
  │<── Answer ─────────────┤                        │
  │                        │                        │
  │<══════ WebRTC P2P 视频流 ═══════════════════════>│
```

## 五、安全机制

### 5.1 认证授权

- JWT Token 认证
- Token 有效期 7 天
- 刷新 Token 机制

### 5.2 设备授权

- 首次登录需设备确认
- 异常登录告警
- 设备可远程注销

### 5.3 通信加密

- WebSocket over TLS (WSS)
- HTTPS 全站加密
- WebRTC DTLS 加密
