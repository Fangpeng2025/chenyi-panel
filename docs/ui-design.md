# 晨翼Agent v1.0 前端UI设计文档

## 一、设计原则

### 核心原则
- **任务为中心**：所有功能围绕任务展开
- **AI驱动**：自然语言创建任务，智能理解用户意图
- **实时同步**：所有设备实时同步显示任务状态
- **设备无关**：在任意设备上操作体验一致
- **简洁高效**：常用功能一键触达

### 导航结构

**手机端（底部导航）**
```
┌─────────────────┐
│ 🏠 首页         │
│ 📋 任务         │
│ 🤖 AI助手       │
│ 📱 设备         │
│ ⚙️ 设置         │
└─────────────────┘
```

**电脑端（侧边栏导航）**
```
┌─────────────────┐
│ 🏠 首页         │
